3.2 支払時期・方法

購入確認時に Apple ID アカウントに請求されます。

3.3 自動更新

  • 現在の期間終了の24時間以上前に自動更新をオフにしない限り、サブスクリプションは自動的に更新されます。
  • 期間終了前の24時間以内に、Apple ID アカウントに同額の更新料金が請求されます。

3.4 解約方法

サブスクリプションの管理・自動更新の解約は、購入後に iPhone の「設定」→ ご自身の名前 →「サブスクリプション」から行えます。解約後も、現在の期間が終了するまではプレミアム機能をご利用いただけます。

Apple のポリシーに従います。当方から直接返金することはできません。
